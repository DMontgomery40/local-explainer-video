For each scene, you write a Remotion React component as a `scene_code` string. This code will be dynamically compiled and rendered to video at 1664x928, 30fps.

AVAILABLE REMOTION APIs (already imported for you — do NOT write import statements):
- React (hooks: useState, useEffect, useMemo, useRef, useCallback)

- Sequence — time-offset child elements

- spring({frame, fps, config?}) — physics-based 0→1 animation

- Easing — easing functions for interpolate
- staticFile(path) — reference files in public/ folder

QUALITY BAR — THIS IS WHAT GOOD LOOKS LIKE:
Each scene should be a premium piece of motion graphics. Think Apple keynote, not PowerPoint. Specifically:

1. ANIMATED DATA VISUALIZATIONS — not text on a dark background.
   - For before/after metrics: animated ring charts or arc gauges that fill up with the value, color-coded (red/amber for concerning, green/teal for in-target). Show target range as a subtle arc zone.
   - For multi-session data: show all sessions as a row of ring charts or gauges, staggered animation, with arrows and delta badges between them.
   - For ranked data: animated horizontal bars that grow in with spring physics.
   - For brain regions: SVG or absolute-positioned labels on a brain background with pulsing glow dots at each electrode site, color-coded by status.

2. COLOR SEMANTICS — tell the story before they read a word.
   - Red/coral (#ef4444) = concerning, above/below target
   - Amber/gold (#fbbf24) = transitional, improving but not there yet
   - Green/teal (#4fd1c5 or #34d399) = healthy, in target, improved
   - Blue (#63b3ed) = neutral/informational
   - Use these consistently. A patient should understand "green = good" at a glance.

3. ANIMATED REVEALS — choreographed, staggered.
   - Use spring() for organic motion. Config suggestions:
     - Smooth subtle: { damping: 200 }
     - Snappy entrance: { damping: 20, stiffness: 200 }
     - Bouncy: { damping: 8 }
   - Stagger elements: delay each by 6-10 frames
   - Numbers should count up (interpolate frame to target value)
   - Bars/rings should fill over ~1 second

4. BACKGROUNDS — dark premium gradients, not flat black.
   - Base: linear-gradient(160deg, #0a0e1a, #060a14)
   - Can use staticFile("backgrounds/X.png") for brain images:
     brain_region_focus_topdown.png, brain_region_focus_heatmap.png,
     neural_network_abstract.png, cover_hook.png, closing_cta.png,
     analogy_orchestra.png, analogy_rowing.png, analogy_fog_lifting.png, etc.
   - Layer background images with brightness filter + gradient overlay for readability

5. TYPOGRAPHY — clean hierarchy.
   - Headlines: 42-56px, bold, white, text-shadow for depth
   - Metric labels: 12-14px, uppercase, letter-spacing 2-4px, muted color
   - Values: 32-48px, bold, color-coded
   - Body: 18-22px, light weight, #94a3b8
   - Font stack: 'Inter', 'Helvetica Neue', sans-serif

6. LAYOUT — fill the frame purposefully.
   - No massive dead space. Every section of the 1664x928 canvas should contribute.
   - Use flexbox for centering and distribution.
   - Pad content 40-80px from edges.

7. CANVAS RENDERING — for complex visualizations you can use useRef + canvas:
   - Animated arc gauges with glow effects
   - Particle backgrounds
   - Custom chart rendering
   - This runs in a browser context so Canvas2D is available

8. EACH SCENE MUST BE VISUALLY UNIQUE. Do not reuse the same layout across scenes. The video should feel like 15 different frames of a documentary, not 15 variations of the same slide.
